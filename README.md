# Egu Generator

**Egu Generator** は、Minecraft Forge 1.20.1 向けに開発された、超大容量のエネルギーを生成する発電機MODです。

通常のバランスを大きく超えた発電量と蓄電容量を特徴としています。

| 項目 | 内容 |

## ⚡ 主な機能

- 超大容量のエネルギーを蓄電できる発電機
- 圧縮マグマブロックを利用した発電
- エネルギーを輸送する「えぐケーブル」
- エネルギー量や発電量を確認できる専用GUI
- JEIによるクラフトレシピの確認
- 独自の `long` 型エネルギーAPIによる大容量エネルギー処理

## 🔋 エネルギー仕様

### 発電量

| 燃料ブロック | 発電量 |
|---|---:|
| 圧縮マグマブロック | 50 GFE/t |
| 2倍圧縮マグマブロック | 100 GFE/t |
| 3倍圧縮マグマブロック | 250 GFE/t |

※ 上記は設定値です。実際の発電量は発電機に隣接する燃料ブロックの組み合わせによって変わります。

### 蓄電・送電

| 項目 | 設定値 |
|---|---:|
| 発電機の最大蓄電容量 | 10 TFE |
| 発電機の最大送電速度 | 1,000 TFE/t |

※ 通常のForge Energy APIは `int` 型を使用するため、独自の `long` 型APIに対応していない機械では、大容量エネルギーを一度に転送できない場合があります。

## 📥 導入方法

1. Minecraft 1.20.1 に対応する Forge 47.4.10 をインストールします。
2. Egu Generator の配布JARをダウンロードします。
3. ダウンロードしたJARをMinecraftの `mods` フォルダに配置します。
4. ForgeプロファイルでMinecraftを起動します。

JEIを導入している場合、対応するクラフトレシピをゲーム内で確認できます。

## 🛠️ ソースコードのビルド

### 必要な環境

- Java 17
- Minecraft Forge 1.20.1 MDKを基にした開発環境

### ビルド方法

リポジトリのルートディレクトリで、次のコマンドを実行します。

**Windows**

```powershell
.\gradlew.bat clean build
```

**Linux / macOS**

```bash
./gradlew clean build
```

ビルドに成功すると、通常は `build/libs/` にJARファイルが生成されます。

## 📝 開発について

本リポジトリのソースコードは、V2.0.1のJarファイルをデコンパイルし、AIによるソースコード復元版をベースに、その後の追加修正を反映したものです。

公開時点のソースコードを記録し、今後の修正や機能追加に利用できるようにすることを目的としています。

また、本プログラムのソースコードを一度紛失しております。そのため、V3.0.0以下のバージョンは違う書き方を行っている可能性があります。ご注意ください。
